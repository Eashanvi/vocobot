\# 🤖 VocoBot - Voice Controlled Robot



\## 📌 Overview

A voice-controlled robot using Arduino and Bluetooth.



\## 🛠️ Components

\- Arduino Uno

\- HC-05 Bluetooth Module

\- Motor Driver

\- Ultrasonic Sensor

\- Servo Motor



\## ⚙️ Features

\- Voice control via Bluetooth

\- Obstacle detection

\- Wireless operation



\## 🚀 How to Run

1\. Upload vocobot.ino to Arduino

2\. Connect HC-05 module

3\. Use voice control app
