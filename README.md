\# 🤖 VocoBot - Voice Controlled Robot



\## 📌 Overview



VocoBot is a voice-controlled robotic system built using Arduino Uno and Bluetooth communication. It enables hands-free navigation through voice commands transmitted via a mobile device. The system also integrates obstacle detection using an ultrasonic sensor to ensure safe and intelligent movement.



\## 🛠️ Components



\- Arduino Uno  

\- HC-05 Bluetooth Module  

\- Motor Driver  

\- Ultrasonic Sensor  

\- Servo Motor  



\## ⚙️ Working Principle



Voice commands from a mobile application are transmitted via the HC-05 Bluetooth module to the Arduino Uno. The Arduino processes these commands and controls the motor driver to move the robot accordingly. An ultrasonic sensor continuously monitors obstacles, stopping the robot if an object is detected within a threshold distance.



\## 🎮 Commands



| Command | Action |

|--------|--------|

| F | Move Forward |

| B | Move Backward |

| L | Turn Left |

| R | Turn Right |

| S | Stop |



\## 🚀 How to Run



1\. Upload the code to Arduino Uno using Arduino IDE  

2\. Connect the HC-05 Bluetooth module  

3\. Pair your mobile device with HC-05  

4\. Use a voice control app to send commands
